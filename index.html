Installation

Get started in minutes

Choose the installation method that fits your workflow.

Download for macOS

Universal binary — runs natively on both Apple Silicon (M1/M2/M3) and Intel Macs.

Apple Silicon (arm64) Intel (x64)
1 Download the .dmg file
2 Open it and drag WAutoChat to Applications
3 Launch the app — scan your WhatsApp QR

Download for Windows

NSIS installer — supports Windows 10 and Windows 11 (x64).

Download .exe
1 Download and run the .exe installer
2 If Windows SmartScreen appears, click "More info → Run anyway"
3 Launch WAutoChat and connect your WhatsApp

Download for Linux

AppImage — works on any modern Linux distribution without installation.

Download .AppImage
1 Download the .AppImage
2 Make it executable: chmod +x WAutoChat-*.AppImage
3 Run it: ./WAutoChat-*.AppImage

Self-host with Docker

Deploy WAutoChat on your own server in one command. Includes automatic updates via Watchtower.

docker-compose.yml 
services:
  wautochat:
    image: ghcr.io/aloproagency/wautochat-desktop:latest
    container_name: wautochat
    restart: unless-stopped
    ports:
      - "3000:3000"
    volumes:
      - wautochat_data:/data
    environment:
      - AUTH_SECRET=your_secret_here   # openssl rand -hex 32
      - ADMIN_EMAIL=admin@example.com
      - ADMIN_PASSWORD=your_password

  watchtower:
    image: containrrr/watchtower
    container_name: wautochat-updater
    restart: unless-stopped
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock
    command: wautochat --interval 3600 --cleanup

volumes:
  wautochat_data:
Deploy 
docker compose up -d
Watchtower checks for a new image every hour and restarts the container automatically.
