Installation

Get started in minutes

Choose the installation method that fits your workflow.

Download for macOS

Native app for Apple Silicon (M1/M2/M3/M4) and Intel Macs.

Apple Silicon (arm64) Intel (x64)
1
Open the .dmg and drag to Applications

Double-click the downloaded .dmg file, then drag WAutoChat into your Applications folder.

2
Bypass Gatekeeper (unsigned app)

macOS will block the app on first launch because it is not signed with an Apple certificate. Follow one of these methods:

Method A Right-click (or Control + click) on WAutoChat in Applications → Open → click Open in the dialog that appears.
Method B Try to open normally → get blocked → go to System Settings → Privacy & Security → scroll down → click ”Open Anyway”.
3
Connect WhatsApp

The app will load, then show a QR code — scan it with WhatsApp on your phone to link your account.

Download for Windows

NSIS installer — Windows 10 and Windows 11, x64 and arm64.

Download .exe installer
1
Run the installer

Double-click the downloaded .exe file to start the installation wizard.

2
Bypass Windows SmartScreen

Because WAutoChat is not yet signed with a Microsoft EV certificate, SmartScreen will show a blue warning screen. This is expected — the app is safe.

Click ”More info” on the SmartScreen dialog → then click ”Run anyway” to proceed.
3
Install and launch

Choose your install directory, complete the setup, then launch WAutoChat and scan your WhatsApp QR code.

Download for Linux

AppImage — works on Ubuntu, Debian, Fedora, Arch and any modern distribution. No installation required.

Download .AppImage
1
Make it executable and run

Open a terminal in the folder where you downloaded the file and run:

~ — bash 
# Make executable
$ chmod +x WAutoChat-*.AppImage

# Run
$ ./WAutoChat-*.AppImage
2
Connect WhatsApp

Scan the QR code shown in the app with WhatsApp on your phone.

On some distributions, AppImage requires FUSE. If it does not start, run: sudo apt install libfuse2 (Ubuntu/Debian) or sudo dnf install fuse (Fedora).

Self-host with Docker

Deploy WAutoChat on your own server in one command. Includes automatic updates via Watchtower.

docker-compose.yml 
services:
  wautochat:
    image: ghcr.io/aloproagency/wautochat-desktop:latest
    container_name: wautochat
    restart: unless-stopped
    ports:
      - "3000:3000"
    volumes:
      - wautochat_data:/data
    environment:
      - AUTH_SECRET=your_secret_here   # openssl rand -hex 32
      - ADMIN_EMAIL=admin@example.com
      - ADMIN_PASSWORD=your_password

  watchtower:
    image: containrrr/watchtower
    container_name: wautochat-updater
    restart: unless-stopped
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock
    command: wautochat --interval 3600 --cleanup

volumes:
  wautochat_data:
~ — bash 
# Deploy WAutoChat in one command
$ docker compose up -d
Watchtower checks for a new image every hour and restarts the container automatically.
