Installation

Get started in minutes

Choose the installation method that fits your workflow.

Download for macOS

Native app for Apple Silicon (M1/M2/M3/M4) and Intel Macs.

Apple Silicon (arm64) Intel (x64)
  1. 01 Download the .dmg file
  2. 02 Open it and drag WAutoChat to Applications
  3. 03 If macOS blocks the app — right-click → Open, or System Settings → Privacy & Security → Open Anyway
  4. 04 Launch the app and scan your WhatsApp QR code

Download for Windows

NSIS installer — Windows 10 and Windows 11, x64 and arm64.

Download .exe installer
  1. 01 Download and run the .exe installer
  2. 02 If Windows SmartScreen appears, click "More info → Run anyway"
  3. 03 Launch WAutoChat and scan your WhatsApp QR code

Download for Linux

Debian package (.deb) — recommended for Ubuntu and Debian. Installs system-wide with icon in your application launcher.

Download .deb (amd64) Other Linux (.AppImage)
  1. 01 Download the .deb package
  2. 02 sudo apt install ./WAutoChat-*.deb
  3. 03 Launch WAutoChat from your application menu

Self-host with Docker

Deploy WAutoChat on your own server in one command. Includes automatic updates via Watchtower.

docker-compose.yml 
services:
  wautochat:
    image: ghcr.io/aloproagency/wautochat-desktop:latest
    container_name: wautochat
    restart: unless-stopped
    ports:
      - "47420:47420"
    volumes:
      - wautochat_data:/data
    environment:
      - AUTH_SECRET=your_secret_here   # openssl rand -hex 32
      - ADMIN_EMAIL=admin@example.com
      - ADMIN_PASSWORD=your_password

  watchtower:
    image: containrrr/watchtower:latest
    container_name: wautochat-updater
    restart: unless-stopped
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock
    environment:
      - DOCKER_API_VERSION=1.41
    command: wautochat --interval 3600 --cleanup

volumes:
  wautochat_data:
~ — bash 
# Deploy WAutoChat in one command
$ docker compose up -d
Watchtower checks for a new image every hour and restarts the container automatically.
